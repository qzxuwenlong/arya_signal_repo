# CryptoRounder 交易框架

> 基于 436 条推文提炼

## 框架总览
- **核心理念**: 宏观择时 + 价值投资 + 期权增强收益
- **主战场**: BTC宏观 + MSTR + 山寨币区间交易
- **盈利来源**: mNAV折价买入 + CME缺口 + Wheel策略

---

## 一、BTC 宏观择时

### mNAV 择时法
```
买入信号：
- MSTR 市值 < BTC持仓价值（mNAV < 1.0）
- 通常出现在 MSTR 大跌时
- 等于给BTC打折

卖出信号：
- mNAV > 1.2（溢价过高）
- 或到达目标价
```

### CME缺口策略
```
- 缺口 = 必补锚点
- 回补概率 98%+
- 可用于区间震荡操作
```

---

## 二、期权 Wheel 策略

### 执行步骤
```
1. 选标的（低波动的区间震荡币）
2. 卖出 ATM/OTM put 获得权利金
3. 被行权则持有标的
4. 持有后卖出备兑call
5. 循环往复赚 theta
```

### 适用场景
- 震荡行情（无趋势）
- 高IV环境（权利金更厚）
- 长持标的（不是Meme）

---

## 三、山寨币区间交易

### 买入信号
```
- 下降趋势线突破
- MACD 周线金叉
- 长期震荡区间底部
```

### 卖出信号
```
- 前高假突破 = 颓势信号
- 达到预设止盈位
- 趋势线破位
```

---

## 四、风险管理

- 单项目仓位不超过总资金 15%
- 总期权仓位不超过总资金 30%
- 保留极端现金缓冲（熊市抄底弹药）
- 妖币仓位不超过 5%

---

## 五、每日清单

```
1. 检查 MSTR mNAV 是否有买入机会
2. 监控 CME 缺口位置
3. 检查持仓币 MACD 状态
4. 收权利金（卖期权）
5. 复盘区间交易
```
