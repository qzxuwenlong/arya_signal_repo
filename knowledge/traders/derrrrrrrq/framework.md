## 一、指标系统

### OI + CVD 分析
```
买入信号：
- OI 增加 + 价格盘整 = 庄在积累
- OI 减少 + 价格下跌 = 多头平仓（可能见底）

卖出信号：
- OI 很高 + 价格涨不动 = 庄在出货
- CVD 减少 + OI 增加 + 价格涨 = 庄可能建空
```

### 成交量异动
```
- 成交量突然放大 2x+ = 趋势确认
- 缩量上涨 = 不健康，警惕回调
- 放量下跌 = 趋势延续
```

## 二、Meme/妖币系统

### 现象级新盘（首选）
```
特征：
- 无老筹码压力
- 开盘即爆拉
- 所有资金无脑冲

操作：开盘前/后5分钟内介入，快进快出
```

### 短线突破
```
- 涨幅榜30%的币 = 妖币
- 频繁杀多 = 短线机会
- 情况不对立刻跑路
```

## 三、现货 vs 合约选择

| 场景 | 工具 |
|------|------|
| 长期看好标的 | 现货优先 |
| 短期突破 | 合约 |
| Meme 现象级 | 现货（开盘后）|
| 新手 | 现货，禁止合约 |
