# Arya_web3 可执行交易框架｜重蒸馏版

> 目标：把 Arya_web3 的推文体系转成可用于 OKX/合约热币扫描、人工确认、后续量化系统设计的规则框架。  
> 定位：**信号框架，不是自动下单策略**。任何实盘交易仍需人工确认。

---

## 0. 框架总览

Arya 框架的核心不是“找好币”，而是找 **有 MM 参与、有合约燃料、有交易所通道、有传播热度的短线爆发窗口**。

```text
候选池筛选 → MM/庄行为识别 → 合约燃料验证 → 入场窗口 → 持仓监控 → 退出/反手观察
```

核心原则：

1. 做短线，不做长线；
2. 顺 MM，不和 MM 对赌；
3. OI 必须用爆仓数据验真假；
4. 资金费率极端不是无脑反向，而是尾部风险区；
5. 不盯盘不过夜；
6. 有利润先保护，别幻想从头吃到尾。

## 1. 候选池筛选

### 1.1 标的来源

优先从以下来源进入候选池：

| 来源 | 说明 | 权重 |
|---|---|---:|
| OKX/币安合约热榜 | 已有合约流动性，可观察 OI/费率/爆仓 | 高 |
| 新上合约/新上 Alpha/新上现货 | 事件驱动强，容易出现 MM 行为 | 高 |
| 社区/KOL 高频提及 | 提供传播和对手盘入口 | 中 |
| 链上低市值强社区 meme | 早期机会，但风险高 | 中 |
| 预测市场/事件市场 | 可辅助判断市场预期 | 低-中 |

### 1.2 入池硬条件

满足任意 2 条即可进入观察池：

- 24h 合约成交量显著放大；
- OI 连续上升；
- 资金费率快速偏离常态；
- 多空比或账户比极端；
- 出现大额爆仓；
- 社媒/KOL/社区讨论突然放大；
- 上线 OKX/Binance/Aster/韩国所等关键交易通道；
- 链上数据显示不是庄地址出货，而是早期获利盘释放。

### 1.3 禁止入池/降权条件

- 纯现货且无合约通道；
- FDV/市值过高且无新增流动性入口；
- 上线后持续出货，无明显承接；
- OI 高但成交量和爆仓不匹配；
- 社区热度来自抽奖/刷互动，缺少真实交易量；
- 流动性太薄，点差过大，不适合网格或合约。

## 2. 评分模型 V1

总分 100。用于排序，不用于自动下单。

| 模块 | 权重 | 评分逻辑 |
|---|---:|---|
| 交易所通道 | 15 | OKX/Binance 合约、新上现货、Aster/韩国所等 |
| 合约燃料 | 25 | OI、成交量、费率、多空比是否同步异常 |
| 爆仓验证 | 20 | 是否出现连续爆仓/大额爆仓，验证 OI 真实性 |
| MM/庄行为 | 20 | 急拉急砸、洗盘、回拉、控盘痕迹 |
| 社区/传播 | 10 | KOL/社区/媒体是否持续传播 |
| 风险折扣 | -20 至 0 | 费率极端、OI 虚假、过热、流动性差、庄撤仓 |

### 2.1 分数解释

| 分数 | 状态 | 操作 |
|---:|---|---|
| 80+ | 高优先级 | 人工重点确认，可设计交易计划 |
| 65-79 | 可观察 | 等待入场窗口或更多验证 |
| 50-64 | 普通热度 | 只监控，不交易 |
| <50 | 噪音 | 忽略 |

## 3. 关键数据规则

### 3.1 OI 规则

```text
OI 上升 + 成交量上升 + 爆仓上升 = 有效燃料增加
OI 上升 + 成交量一般 + 爆仓很少 = 可能刷量/庄双开
OI 高位 + 价格不动 = 诱导/控盘/等待对手盘
OI 下降 + 某侧仓位撤退 + 价格顺向 = 庄撤仓/收网风险
```

执行要求：

- 不单独使用 OI 做多/做空；
- 必须同时看成交量、爆仓、价格响应；
- 全网 OI 与单交易所 OI 要对照，防止局部假象。

### 3.2 成交量规则

关注“变化率”大于绝对值：

- 合约成交量 2x 放大：进入重点观察；
- 合约成交量持续放大且 OI 同步上升：趋势升级；
- 成交量放大但价格无方向：可能是换手/诱导；
- 成交量放大 + 价格尖刺 + 大额爆仓：MM 正在兑现。

CHIP 参考阈值：

- 11.8 亿 → 22 亿 → 57 亿全网合约成交量；
- OI 7500 万 → 1.26 亿 → 1.8 亿；
- 爆仓 720 万 → 1960 万。

### 3.3 资金费率规则

```text
费率温和偏离：趋势可能健康
费率快速极端：对手盘压力上升，爆仓机会增加
费率极端 + 新对手盘继续进入：趋势可延续
费率极端 + 对手盘枯竭：MM 一键反手风险上升
```

禁止：

- 看到负费率就无脑做多；
- 看到正费率就无脑做空；
- 在妖币上用“费率太离谱”作为唯一反向理由。

### 3.4 爆仓规则

爆仓是 Arya 体系里的“收益确认信号”。

重点看：

- 是否有 100k+ 单笔爆仓；
- 是否有百万级巨鲸爆仓；
- 爆仓集中在哪个交易所；
- 爆仓方向是否和价格运动一致；
- 爆仓后 OI 是否继续增加。

解释：

- 大额空单被爆 + 价格继续上行：MM 爆空仍有效；
- 大额多单被爆 + OI 下降：可能进入收网/砸盘；
- OI 很高但只有小额爆仓：怀疑刷量。

## 4. 入场模型

### 4.1 模型 A：爆空顺势多

适用：RAVE、CHIP 类妖币。

条件：

1. 价格已出现强势拉升或突破；
2. OI 上升；
3. 成交量放大；
4. 空头占比极端或负费率明显；
5. 已出现空单爆仓，且新空头仍在进入；
6. 社媒出现“太高了我要空”“这币垃圾”等摸顶情绪。

入场方式：

- 不追第一根极端大阳；
- 等急拉后的回踩不破或二次放量；
- 小仓试错，确认爆仓继续后加仓；
- 禁止高杠杆。

失效条件：

- OI 开始下降；
- 空头不再增加；
- 费率极端但价格涨不动；
- 爆仓减少；
- 出现长上影 + 放量滞涨。

### 4.2 模型 B：强庄回调抄底

适用：PEACE 类链上/meme 强庄币。

条件：

1. 前期已有明显拉升和强庄痕迹；
2. 首次大幅回调；
3. 链上显示不是庄地址集中出货，而是早期获利盘释放；
4. 低位出现快速回拉；
5. 社区热度未彻底死亡。

入场方式：

- 只接第一次或第二次高质量回调；
- 等低位回拉确认，不盲目接飞刀；
- 仓位小于合约妖币策略；
- 必须设置止损。

失效条件：

- 庄地址/核心地址持续卖出；
- 回拉失败，低点继续下移；
- 社区变成单纯喊单救盘；
- 夜间无人盯盘。

### 4.3 模型 C：新上合约数据升级

适用：Alpha/新合约标的。

条件：

1. 新上合约或上币路径清晰；
2. FDV 没有离谱到失去拉盘空间；
3. 合约成交量快速放大；
4. OI 阶段性翻倍；
5. 爆仓开始出现；
6. KOL/社区开始传播。

入场方式：

- 第一阶段轻仓观察；
- 数据 2x 放大后进入重点；
- 突破后回踩不破入场；
- 如果开盘 FDV 过高，等待深回调后再看。

失效条件：

- 上线即持续砸盘；
- 无合约通道延续；
- OI/成交量不增长；
- 项目方/DEV 地址异常增发或卖出。

### 4.4 模型 D：庄撤仓/收网做空或退出

适用：TRADOOR 类从拉盘转向收割多头。

条件：

1. 前期已经大幅上涨；
2. 多单减少而空单变化不大；
3. 整体 OI 下降；
4. 价格开始顺势下跌；
5. 资金费率变化提示变盘；
6. 社媒利好开始密集出现但价格不跟。

操作：

- 对已有多头：减仓/清仓；
- 对激进交易：等待反弹失败后小仓试空；
- 禁止在强庄仍爆空时提前摸顶。

失效条件：

- 庄重新拉回关键位；
- OI 再次上升；
- 空军重新成为主要燃料；
- 爆仓方向重新转为空单被爆。

## 5. 持仓管理

### 5.1 仓位原则

| 信号强度 | 建议仓位 |
|---|---:|
| 观察信号 | 0，不交易 |
| 初步确认 | 试探仓 10%-20% |
| 多因子共振 | 标准仓 30%-50% |
| 爆仓趋势确认 | 可加仓，但总风险固定 |
| 尾部风险区 | 减仓，不加仓 |

注意：这里的百分比是“策略资金内部权重”，不是账户总资产比例。

### 5.2 止损原则

Arya 原文强调“不盯盘就空仓/设置止损止盈”。系统化为：

- 硬止损：入场逻辑失效立即出；
- 时间止损：数据不继续强化则退出；
- 结构止损：跌回突破区间/回拉失败；
- 尾部止损：费率极端 + 爆仓减少 + OI 下滑。

### 5.3 止盈原则

- 第一目标：先收回风险敞口；
- 第二目标：跟随爆仓趋势；
- 第三目标：出现燃料枯竭迹象时主动退出；
- 不追求从头吃到尾。

可执行模板：

```text
入场后盈利达到 R1：减 25%-33%
爆仓继续 + OI 增加：持有剩余
费率极端 + 价格滞涨：再减 25%-50%
OI 下降/爆仓减少/长上影：清仓
```

## 6. 风险状态机

### 6.1 正常区

特征：

- OI 温和增加；
- 成交量增加；
- 费率未极端；
- 爆仓开始但不疯狂。

动作：可持有/观察加仓。

### 6.2 爆仓加速区

特征：

- 单边急拉/急砸；
- 对手盘爆仓持续出现；
- 社媒开始出圈；
- 新对手盘继续进入。

动作：持有趋势仓，但不高杠杆追。

### 6.3 尾部高危区

特征：

- 费率极端；
- OI 巨大；
- 价格越来越依赖新对手盘；
- 媒体/KOL 全面出圈；
- 爆仓金额巨大。

动作：只减不加，等待退出信号。

### 6.4 收网区

特征：

- OI 下降；
- 原主导方向仓位撤退；
- 价格反向加速；
- 利好密集但价格不涨；
- 长上影/长下影频繁。

动作：退出；激进者可反向小仓，但必须确认。

## 8. 初版信号公式

### 8.1 MM 爆空评分

```text
short_squeeze_score =
  0.25 * oi_growth_score
+ 0.20 * volume_growth_score
+ 0.20 * short_liquidation_score
+ 0.15 * funding_extreme_score
+ 0.10 * social_momentum_score
+ 0.10 * price_breakout_score
- 0.20 * tail_risk_score
```

高分含义：MM 可能继续向上爆空。

### 8.2 MM 收网风险评分

```text
exit_risk_score =
  0.25 * oi_decline_score
+ 0.20 * price_stall_score
+ 0.20 * funding_extreme_score
+ 0.15 * liquidation_slowdown_score
+ 0.10 * long_wick_score
+ 0.10 * hype_overheat_score
```

高分含义：停止加仓，减仓或退出。

### 8.3 OI 真假校验

```text
oi_validity_score =
  0.35 * liquidation_match_score
+ 0.25 * volume_match_score
+ 0.20 * price_response_score
+ 0.20 * cross_exchange_consistency_score
```

低分含义：OI 可能刷量/庄双开，不参与。

## 9. 人工确认清单

每个候选币交易前必须回答：

1. 它为什么现在动？
2. 是谁在拉/砸？
3. OI 增加是真对手盘还是刷量？
4. 爆仓是否验证了 MM 正在赚钱？
5. 资金费率处于健康区、加速区还是尾部区？
6. 新对手盘是否还在进入？
7. 如果我错了，哪个数据会首先证明我错？
8. 如果我睡觉/离线，会不会暴露在庄币过夜风险里？
9. 这笔交易适合网格、趋势还是只适合观察？
10. 是否已经得到用户明确确认？

## 10. 与网格系统的关系

Arya 框架不天然等于网格策略。适配方式：

### 10.1 适合网格的状态

- 有波动但不是单边极端；
- OI/费率未进入尾部高危；
- 流动性足够，点差低；
- 价格在 MM 洗盘区间内反复震荡。

### 10.2 不适合网格的状态

- 爆仓加速单边行情；
- 费率极端 + 即将反手；
- 流动性薄、插针频繁；
- 庄撤仓/收网阶段。

### 10.3 推荐系统分工

```text
Arya 模型：负责发现“庄/MM 正在制造机会或风险”
OKX 热币评分：负责筛选流动性、波动、费率、点差
网格 bot：只在适合震荡收割的状态执行
人工确认层：决定是否允许交易
```

## 11. 最小可运行策略设计方向

下一步交易系统可以从这三个模块开始：

### 模块 A：热币候选池

- OKX swap 全市场扫描；
- 5m/15m/1h 涨跌幅；
- 24h 成交额；
- 点差/深度过滤。

### 模块 B：Arya-MM 行为评分

- OI 变化；
- funding 变化；
- 成交量变化；
- 爆仓数据；
- 价格突破/插针。

### 模块 C：交易模式分类

输出三类：

```text
WATCH_ONLY      只观察
GRID_ALLOWED    可开网格
TREND_ALERT     趋势/爆仓行情，不开普通网格
EXIT_RISK       停止/退出风险
```

## 12. 最终执行纪律

1. 没有合约燃料，不交易；
2. OI 未经爆仓验证，不交易；
3. 妖币不主观摸顶；
4. 极端费率区只减不加；
5. 不盯盘不过夜；
6. 任何订单必须用户明确确认；
7. 系统先做监控和评分，不直接自动执行。
