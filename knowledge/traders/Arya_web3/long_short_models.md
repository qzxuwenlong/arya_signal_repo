## 0. 总原则

Arya 的多空不是传统技术分析里的“涨了看多、跌了看空”，而是判断 **MM/庄当前更想收割哪一侧对手盘**。

核心逻辑：

```text
交易所通道 / 热度入口
  ↓
合约战场形成：OI、成交量、资金费率、多空比
  ↓
MM 选择方向制造波动
  ↓
爆仓兑现：爆空 → 偏多；爆多 → 偏空
  ↓
燃料衰竭 / OI 下降 / 费率极端 → 退出或反向观察
```

因此：

- **做多模型**：不是因为币好，而是因为空头燃料足、MM 有动力继续向上爆空。
- **做空模型**：不是因为涨多了，而是因为多头燃料暴露、庄开始撤仓/砸盘/收网。
- **禁止自动下单**：模型只输出候选、方向、证据、风险和人工确认清单。

## 1. 做多模型 A：爆空顺势多

### 1.1 适用场景

适用于 RAVE、CHIP 这类合约妖币/热点币：

- 已有 OKX/Binance 合约通道；
- 市场开始讨论“涨太多了、我要空”；
- OI、成交量、爆仓同步放大；
- MM 通过拉盘收割空头。

### 1.2 核心假设

```text
如果价格上涨 + OI 增长 + 成交量放大 + 空头爆仓显著，
且新空头仍继续进场，
则上涨不是普通拉升，而是 MM 爆空行情，趋势可能延续。
```

### 1.3 必要条件

满足越多，信号越强：

1. `price_change_1h_pct > 0`，最好有突破或强势回踩不破；
2. `volume_change_1h_pct > 0`，且 1h 成交量明显高于过去均值；
3. `oi_change_1h_pct > 0`，说明合约战场扩大；
4. `short_liq_1h_usd > long_liq_1h_usd`，且差距明显；
5. funding 未进入不可持续极端区，或虽极端但新空头仍持续补充；
6. orderbook depth 足够，spread 不大；
7. 社媒出现摸顶/质疑/空军情绪。

### 1.4 强确认信号

- 空头爆仓出现大额单笔或连续爆仓；
- OI 与成交量阶段性翻倍；
- 拉升后回踩不破，随后二次放量；
- 价格上涨时 OI 不塌，说明燃料还没消失；
- 负 funding 下仍继续上涨，表示空头付费压力正在被 MM 利用。

### 1.5 入场方式

不追第一根极端大阳，优先：

```text
强拉 → 回踩不破 → OI 不降 → 成交量维持 → 空头继续爆仓 / 新空继续进场 → 小仓试多
```

操作纪律：

- 小仓试错；
- 不高杠杆；
- 确认爆仓继续后再考虑加仓；
- 收益先保护，不幻想从头吃到尾。

### 1.6 失效条件

出现以下情况，多头模型降级或退出：

- OI 开始下降；
- 空头不再增加；
- 爆仓减少；
- funding 极端但价格涨不动；
- 长上影 + 放量滞涨；
- 价格跌回突破区间；
- 社媒全面一致看多，摸顶空军消失。

### 1.7 系统输出映射

```text
状态：SQUEEZE_ACTIVE / TREND_ALERT
方向：偏多
策略：爆空顺势 / 趋势跟随
允许自动交易：否
人工动作：重点确认，可制定多头计划
```

## 2. 做多模型 B：强庄回调抄底

### 2.1 适用场景

适用于 PEACE 类链上/meme 强庄币：

- 前期已有明显拉升；
- 首次或第二次大幅回调；
- 链上/盘口显示不是庄集中出货，而是早期获利盘释放；
- 低位出现强回拉；
- 社区未死亡。

### 2.2 核心假设

```text
如果强庄币大幅回调，但庄地址没有集中出货，
且低位快速回拉，说明庄仍在维护价格，
可以把回调视为短线试多窗口，而不是长期价值买入。
```

### 2.3 必要条件

1. 前期存在强庄/强 MM 痕迹；
2. 回调是首次或第二次高质量回调；
3. 低位快速回拉，而不是连续阴跌；
4. 成交量放大但未出现彻底出货结构；
5. 社区仍有活跃传播；
6. 若有链上数据，庄地址没有持续卖出。

### 2.4 入场方式

```text
前期强势 → 大回调 → 低位止跌 → 快速回拉 → 小仓试多
```

纪律：

- 不盲目接飞刀；
- 只做短线；
- 必须止损；
- 仓位低于爆空趋势模型；
- 不盯盘不持仓过夜。

### 2.5 失效条件

- 庄地址/核心地址持续卖出；
- 回拉失败，低点继续下移；
- 社区只剩喊单救盘；
- OI/成交量无法恢复；
- 夜间无人盯盘。

### 2.6 系统输出映射

```text
状态：TREND_ALERT / WATCH_ONLY
方向：偏多
策略：强庄回调 / 短线反弹
允许自动交易：否
人工动作：只在回拉确认后小仓，不做长线信仰
```

## 3. 做空模型 A：庄撤仓 / 收网做空

### 3.1 适用场景

适用于 TRADOOR 类从拉盘转向收割多头的结构：

- 前期已经大幅上涨；
- 多头仓位减少或被动爆仓；
- 整体 OI 下降；
- 价格顺势下跌；
- 利好密集但价格不涨；
- 庄/MM 可能开始收网。

### 3.2 核心假设

```text
如果前期强势币开始 OI 下降，价格同步下跌，
多头减少 / 多头爆仓显著，而空头没有被持续爆掉，
则可能不是普通回调，而是庄撤仓、砸盘、收网。
```

### 3.3 必要条件

1. 前期已有明显涨幅或高位结构；
2. `price_change_1h_pct < 0`，价格开始顺势下跌；
3. `volume_change_1h_pct > 0`，下跌伴随放量；
4. `long_liq_1h_usd > short_liq_1h_usd`，多头爆仓显著；
5. OI 下降或 OI 增长但价格继续跌，说明多头被动接刀；
6. funding 变化提示多头拥挤或变盘；
7. 反弹失败，无法重新站回关键位。

### 3.4 强确认信号

- 大额多单爆仓；
- OI 下降 + 价格下跌；
- 利好/KOL 喊多但价格不涨；
- 每次反弹都缩量或被砸回；
- 多头爆仓后没有快速修复；
- orderbook 上方卖压明显。

### 3.5 入场方式

禁止直接在强庄爆空行情中摸顶。更稳妥方式：

```text
高位滞涨 → 首轮下跌放量 → 反弹失败 → OI/多头爆仓继续恶化 → 小仓试空
```

纪律：

- 只做确认后的反弹失败；
- 不在第一根瀑布后盲目追空；
- 止损放在重新站回关键位 / OI 再次转强处；
- 若空头重新成为主要燃料，立刻退出空头想法。

### 3.6 失效条件

- 价格重新站回关键位；
- OI 再次上升且价格上涨；
- 空头爆仓重新占主导；
- funding 重新变成空头拥挤，MM 有动力爆空；
- 社媒开始一致看空，空头燃料过度拥挤。

### 3.7 系统输出映射

```text
状态：SHORT_ALERT
方向：偏空
策略：做空/瀑布/收网
允许自动交易：否
人工动作：等待反弹失败后确认，不主观摸顶
```

## 4. 做空模型 B：尾部高危反手观察

### 4.1 适用场景

适用于已经经历爆空上涨后的尾部阶段：

- 费率极端；
- OI 巨大；
- 爆仓金额巨大；
- 价格越来越依赖新空头进场；
- 媒体/KOL 全面出圈；
- 多头开始拥挤，MM 可能一键 sell。

### 4.2 核心假设

```text
极端上涨后不能立刻做空，
但当空头燃料枯竭、多头变成新流动性来源、价格滞涨时，
市场从“爆空趋势”进入“反手观察区”。
```

### 4.3 观察条件

1. 价格仍高位，但上涨效率下降；
2. funding 极端；
3. OI 高但价格不再有效上行；
4. 空头爆仓减少；
5. 多头追涨明显增加；
6. 长上影、插针、放量滞涨频繁出现。

### 4.4 操作方式

- 对已有多头：只减不加；
- 对空头候选：只观察，不立刻空；
- 等待反弹失败 / OI 下降 / 多头爆仓后再进入做空模型 A。

### 4.5 系统输出映射

```text
状态：EXIT_RISK / WATCH_ONLY
方向：中性偏空观察
策略：尾部风险 / 等待收网确认
允许自动交易：否
人工动作：多头减仓，空头等待确认
```

## 5. 多空方向判定表

| 市场结构 | 偏多/偏空 | 系统状态 | 解释 |
|---|---|---|---|
| 价格涨 + OI 涨 + 成交放大 + 空头爆仓 | 偏多 | `SQUEEZE_ACTIVE` | MM 爆空，趋势可能延续 |
| 价格涨 + OI 涨 + 无爆仓 | 观察 | `WATCH_ONLY` | OI 可能刷量/庄双开 |
| 价格涨 + funding 极端 + 价格滞涨 | 风险 | `EXIT_RISK` | 尾部高危，不能加多 |
| 价格跌 + 成交放大 + 多头爆仓 | 偏空 | `SHORT_ALERT` | 多头被收割，可能瀑布 |
| 价格跌 + OI 降 + 多单撤退 | 偏空 | `SHORT_ALERT` / `EXIT_RISK` | 庄撤仓/收网 |
| 价格跌 + OI 涨 + 空头拥挤 | 谨慎 | `WATCH_ONLY` | 小心诱空后爆空 |
| 价格震荡 + 深度好 + 费率正常 | 中性 | `GRID_ALLOWED` | 更适合网格，不是趋势 |
| 流动性薄 + 点差大 + 插针多 | 禁止 | `EXIT_RISK` | 不适合交易 |

## 6. 可接入 Arya 代码的规则字段

### 6.1 做多字段

```text
long_score =
  + price_up_score
  + volume_growth_score
  + oi_growth_score
  + short_liquidation_score
  + funding_pressure_score
  + breakout_score
  - tail_risk_score
  - liquidity_risk_score
```

建议映射：

- `price_change_1h_pct > 0`
- `volume_change_1h_pct > 50`
- `oi_change_1h_pct > 0`
- `short_liq_1h_usd / long_liq_1h_usd > 2`
- `breakout_score` 高
- `spread_pct` 低
- `depth_usd` 足够

### 6.2 做空字段

```text
short_score =
  + price_down_score
  + volume_growth_score
  + long_liquidation_score
  + oi_decline_or_bearish_oi_score
  + failed_rebound_score
  - short_crowding_risk_score
  - liquidity_risk_score
```

建议映射：

- `price_change_1h_pct < 0`
- `volume_change_1h_pct > 50`
- `long_liq_1h_usd / short_liq_1h_usd > 2`
- `oi_change_1h_pct < 0` 或 `oi_change_1h_pct > 0` 但价格继续跌
- `range_position_24h_pct` 从高位回落
- `trend_strength < 0`
- `spread_pct` 低
- `depth_usd` 足够

## 7. 人工确认清单

每个多头信号确认：

1. 是谁在拉？交易所通道和 MM 痕迹是否存在？
2. 空头是否真的是燃料，而不是庄自刷 OI？
3. 空头爆仓是否已经出现？是否还在继续？
4. funding 极端后，是否还有新空军进场？
5. 入场是追高还是回踩确认？
6. 如果 OI 下降/爆仓减少，是否立即退出？

每个空头信号确认：

1. 是真的庄撤仓/收网，还是普通洗盘？
2. 多头爆仓是否显著？
3. 价格是否反弹失败，而不是刚刚开始回调？
4. 空头是否已经拥挤到反而会成为燃料？
5. 重新站回哪个位置证明做空失效？
6. 是否只是“涨多了想空”的主观冲动？

---

## 8. 最终纪律

1. 不因“币好”做多，只因 MM/燃料/数据共振做多。  
2. 不因“涨多了”做空，只因庄撤仓/多头爆仓/反弹失败做空。  
3. OI 必须验证真假；爆仓是最重要验证来源之一。  
4. 费率极端是风险区，不是机械反向信号。  
5. 妖币短线为主，不盯盘不过夜。  
6. 所有信号只是分析，不能自动下单。  
7. 实盘交易必须用户明确确认。
