# Arya_web3 交易框架

> 基于 829 条推文提炼的可执行交易框架

## 框架总览

**核心理念**: 跟庄、做 MM 的对手盘的对手盘
**核心工具**: 合约数据 + 链上分析
**主战场**: Binance 合约
**盈利来源**: MM 爆仓收割 + 趋势跟随

## 一、选币系统

### 优先级评分

| 指标 | 权重 | 说明 |
|------|------|------|
| 币安合约上线 | 30% | 有合约才有 MM，才有流动性 |
| FDV < 2亿 | 20% | FDV 太高=太贵，庄不愿意拉 |
| 有强庄 | 25% | 看 K 线走势、社区、链上地址 |
| 社区热度 | 15% | KOL 喊单、讨论度 |
| 链上健康 | 10% | 早期获利盘出货 ≠ 庄地址出货 |

### 红灯（禁止买入）
- 纯现货，无合约
- FDV > 5亿
- 上线后一直出货无反弹
- 无 MM 做市

## 二、入场系统

### 信号 1：MM 吸筹信号（首选）
```
条件：
- OI 持续增加（1.5x-2x）
- 价格在某个区间震荡
- 巨鲸空单被爆（hyperliquid 数据）
- 成交量萎缩后突然放大

操作：等 MM 向下扫止损后买入（假突破）
```

### 信号 2：资金费率异动
```
条件：
- 1小时/4小时资金费率快速升高
- 多空比失衡（空头 > 多头 2x+）
- 爆仓数据显示空军被爆

操作：等费率见顶后，MM 反手拉盘，追多
```

### 信号 3：突破确认
```
条件：
- 突破关键压力位（压力位 = 历史成交密集区）
- FDV 突破心理关口（如 1亿→2亿）
- OI + 成交量同步放大

操作：突破后回踩不破入场
```

### 信号 4：KOL 跟单
```
条件：
- KOL（尤其是有 MM 资源的）喊单
- 项目处于早期（alpha 或首发）
- FDV < 5000万

操作：喊单后回调买入，不追高
```

## 三、持仓管理

### 止损
- **硬止损**: 亏损 20% 必须出
- **时间止损**: 持有超过 48h 无动静，出
- **移动止损**: 买入后最高点回撤 15% 出

### 止盈
- **分批**: 先进 50%，涨 30% 出 25%，剩下跟趋势
- **不贪**: 看到 MM 开始反向操作就走（MM 一键 sell 前兆：资金费率拉满）

## 四、风险识别

### MM 要出货的信号
- OI 很高但价格涨不动 → 庄在出货
- 消息面配合拉盘（利好满天飞）→ 掩护出货
- FDV 奇高 + 无实际用例 → 纯割韭菜

### 绝对不做的事
1. 做空有 MM 的妖币（MM 会拉爆你）
2. 在资金费率拉满时做空（变盘前兆）
3. 持有合约标的的逆向仓位过夜
4. 买 FDV > 10 亿的"价值币"

## 五、数据工具箱

### 每日检查清单

**Binance 合约数据源**:
- 全网合约成交量（24h）
- OI 持仓量（各交易所）
- 资金费率（每小时）
- 多空比
- 24h 爆仓数据（盯巨鲸）

**链上工具**:
- 查地址是否庄地址（出货 vs 获利了结）
- Etherscan / BSCScan

**社区信号**:
- alpha 首发日历
- 42space 预测市场（代币上线时间预测）
- KOL 社群（羊姐社区、Yoda、Ccweb3hub）

## 六、执行流程（每日）

```
1. 扫合约数据 → 找 OI/成交量异动的币
2. 排除 FDV 过高标的
3. 确认有 MM 做市（币安合约 + 高资金费率）
4. 等 K 线/链上入场信号
5. 买入 + 设止损
6. 持仓监控（盯资金费率 + OI 变化）
7. 止盈或止损出局
8. 复盘记录
```
