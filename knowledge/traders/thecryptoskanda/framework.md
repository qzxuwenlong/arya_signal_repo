## 一、三盘分析系统

### 第一步：识别盘主
```
谁是这个项目的真正受益方？
- 代币持有者？
- 基金会？
- 团队？
- 外部资本？
```

### 第二步：识别社区长
```
社区长的角色：
- 代投？分销渠道？
- 是否从盘主处拿额外利益？
- 是否和盘主利益一致？
```

### 第三步：判断自己位置
```
你属于哪一层？
- 跟着社区长走 = 信息劣势
- 自己研究 = 可能找到社区长看不到的机会
```

## 二、DeFi 协议安全评估

### 必查清单
1. **fail-safe 机制** — 出问题时能否自动停止/回滚？
2. **审计报告** — 但不能迷信（审计公司不负责赔）
3. **时间锁** — 团队/管理员是否有紧急修改权限？
4. **跨链桥** — 提现时间锁是否统一？

### 红旗信号
- 合约无 fail-safe
- 多签权限集中在少数人
- 无时间锁的紧急操作权限
