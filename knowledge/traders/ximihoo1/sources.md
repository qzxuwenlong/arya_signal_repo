## 7. 蒸馏方法

1. 使用 X API v2 拉取用户时间线，最多 1000 条；
2. 保留 tweet id、url、created_at、text、public_metrics、entities、referenced_tweets；
3. 按宏观周期、BTC/ETH、山寨/meme、技术分析、衍生品、风险、交易所、社区进行关键词归类；
4. 用互动加权分数筛选证据，但不把互动高低等同于交易价值；
5. 将观点拆成可测试规则：候选池、过滤器、状态机、风控、仓位限制；
6. 严格保持“不自动下单”，只输出交易建议与人工确认提示。

## 8. 限制

- 当前时间范围仅覆盖约 14 天的最近 1000 条；如果账号发文频率很高，历史周期观点可能仍不完整；
- 图片/视频中的图表没有完全 OCR，部分技术细节可能在图片里；
- X API 指标为抓取时刻数据，后续互动会变化；
- 本蒸馏不能替代回测，只能作为知识过滤因子。
