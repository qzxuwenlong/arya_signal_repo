## 1. 一句话画像

@ximihoo1 的核心交易观是：**顺势而为，用大周期资产轮动决定方向，用 BTC / 美股 / 黄金白银 / 微策略等跨资产相对强弱确认阶段，再用 KDJ、MACD、清算地图等细节工具捕捉风险点和短期猎杀。**

她不是典型的短线 meme 猎手，而更像“周期资产轮动 + 技术结构 + 宏观叙事”的交易观察者：

- 大方向：看周期，看资产轮动，看 BTC 在全球支付/交易量中的统治力。
- 中周期：用 BTC、美股、黄金白银、微策略之间的强弱和位置判断资金在哪类资产里轮动。
- 技术细节：关注 2 日 / 3 日级别 MACD、KDJ 结构、价格与指标背离。
- 风险语言：当目标区间完成、价格进入高位、黄金白银出现 0 轴下死叉、清算地图显示多空猎杀时，强调不要追高。
- 执行态度：更偏“提前判断阶段与风险”，不是等新闻确认后追。

## 2. 核心理论：周期资产轮动

### 2.1 市场不是单币种孤立运动，而是资产间轮动

样本中多次出现：

- “周期资产轮动”
- “当前资产轮动阶段，你最看好哪个？”
- “微策略 vs 比特币，你们观察出来什么没？”
- “黄金和白银，危”
- “关于美股，我给的答案最直接”

这说明她的框架不是只看 BTC 一张图，而是把 BTC 放到更大的资产网络里：

```text
BTC ↔ 美股 ↔ 黄金/白银 ↔ 微策略/MSTR ↔ AI/降息/生产力叙事
```

在她的体系里，一个资产是否值得追，不只看自己涨没涨，还要看：

1. 当前市场资金处在哪个大周期阶段；
2. 哪类资产刚完成目标，哪类资产还在补涨；
3. 哪类资产已经进入风险区；
4. 哪类资产的技术结构还没走完。

### 2.2 顺势而为不是追涨，而是识别趋势阶段

她的简介写着“顺势而为，专注：周期资产轮动”。结合样本推文，顺势并不等于任何上涨都追，而是：

- 趋势没走完时，承认强势；
- 目标完成后，不盲目追高；
- 技术指标出现顶背离/死叉风险时，提高防守；
- 清算地图显示短期猎杀时，理解短期推动力，但不把它误判成长期趋势。

代表证据：

> “比特币已完成4月目标：$75K-80K，目前盘面风险较高，不要盲目追高了。”

这句话体现了她的关键原则：**目标位达成后，趋势再强也要切换到风险评估模式。**

## 3. BTC 作为周期锚点

### 3.1 BTC 是资产轮动的主锚

样本里 BTC 出现频率最高，且承担三种角色：

1. **宏观资产锚**：通过支付/交易量叙事证明 BTC 的长期统治力。
2. **周期节奏锚**：用 BTC 目标区间、MACD/KDJ 判断周期阶段。
3. **清算猎杀锚**：短期用清算地图判断爆多/爆空方向。

代表证据：

> “2025年Bitcoin在支付/交易领域的交易量已经远超 Visa、Mastercard，显示强势‘统治力’+增长势头，可这才刚刚开始。”

这个叙事不是短线信号，而是长期资产配置信仰：BTC 的基本面叙事仍在增强。

### 3.2 但 BTC 达到阶段目标后不能追高

同一批推文里，她既强调 BTC 强势，也强调 BTC 完成目标后的风险：

> “比特币已完成4月目标：$75K-80K，目前盘面风险较高，不要盲目追高了。”

这说明她不是无脑多头。她会区分：

```text
长期看好 ≠ 当前点位适合追多
趋势正确 ≠ 任意价格都值得进场
目标完成 ≠ 继续加仓
```

## 4. 技术分析核心：KDJ / MACD / 背离 / 多日级别

### 4.1 顶背离是高位风险信号

样本中有明确教学型推文：

> “KDJ顶背离和MACD顶背离相似，都是：指标向下，而价格却创下新高。”

可抽象成规则：

```text
如果价格创新高，但 KDJ 或 MACD 没有同步创新高，反而向下：
    说明上涨动能衰减；
    高位追多风险上升；
    应从进攻模式切换为止盈/防守/等待回踩。
```

### 4.2 多日级别优先于低级别噪音

她提到：

- “比特币2日级别MACD不会死叉”
- “透过3日级别KDJ看，结构2明显比结构1走的时间更长，而且更强劲”

这说明她看结构时偏向 2D / 3D 级别，而不是 5m/15m 高频噪音。

对我们的系统来说，可以转化为：

```text
优先读取 1D / 2D / 3D K线结构；
短周期信号只能作为入场/退出微调，不能覆盖大周期方向。
```

### 4.3 0 轴下 MACD 死叉是危险结构

黄金白银推文：

> “日级别MACD，如果在这个位置（0轴之下死叉），那么将引来深深的急跌。”

抽象规则：

```text
日线 MACD 位于 0 轴下方，且发生死叉：
    不是普通回调；
    是趋势弱势中的二次转弱；
    容易触发深跌；
    不适合抄底。
```

## 5. 清算地图：短期猎杀方向

样本中有：

> “清算地图：左图1日，右图30日，短期爆空，长期爆多。”

这是一条很重要的结构思想：**不同时间窗口的清算压力方向可能相反。**

可执行理解：

```text
1日清算图：看短期价格更容易先去扫哪边；
30日清算图：看中长期堆积风险和潜在反向目标；
如果 1D 爆空、30D 爆多：
    短线可能先上冲扫空；
    但更大级别可能仍有向下清理多头杠杆的风险。
```

这非常适合接入我们的 V1.5 本地燃料指标：

- 短期 OI 上升 + 价格上冲 + 空头清算密集 → squeeze 风险；
- 长期 OI 过热 + 多头清算密集 + 目标位完成 → exit risk；
- 1D 与 30D 清算方向冲突 → 降低信号置信度，标记为“双周期冲突”。

## 6. 风险观：目标完成后防追高

她的风险观不是“跌了才危险”，而是：

```text
涨到目标区间后，反而危险；
指标背离后，反而危险；
弱势区死叉，反而危险；
市场一致看多后，反而危险。
```

尤其是 BTC 完成 4 月目标后的表达：

> “目前盘面风险较高，不要盲目追高了。”

转成交易纪律：

1. 目标位前，可以顺势；
2. 目标位附近，减少追单；
3. 目标位达成后，只做两类动作：
   - 等回踩确认；
   - 观察是否出现新一轮结构延伸；
4. 若同时出现顶背离/清算多头堆积/Funding 过热，应切换到退出风险模式。
