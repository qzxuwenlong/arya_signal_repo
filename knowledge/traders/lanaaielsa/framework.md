## 二、分流预判系统

### 信号

### 操作
```

2. 立刻链上翻钱包（查大户建仓）
3. 第一时间买入
4. 等上所后出货
```

## 三、Meme 现象级新盘

### 特征识别
```
- 全新盘子（无历史高点/老筹码）
- 开盘即爆拉（k线笔直）
- 所有人无脑冲（资金涌入）
- 有社区/叙事驱动
```

### 操作
```
1. 开盘前/后5分钟内介入
2. 设止损（5-10%）
3. 趋势持有（不轻易出）
4. 反转立刻走
```

## 四、仓位管理

- 总Meme仓位 ≤ 总资金 10%
